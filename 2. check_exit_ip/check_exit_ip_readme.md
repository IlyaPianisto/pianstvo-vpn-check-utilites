# check_exit_ip — проверка выходного IP конфигов

Утилита берёт JSON-файл с Xray-конфигами, по очереди запускает каждый конфиг через встроенный `xray.exe`, делает запрос к сервису определения IP через локальный прокси и записывает в CSV реальный выходной IP, страну, город и провайдера.

Позволяет понять, что на самом деле стоит за конфигом: тот ли это сервер, тот ли провайдер, не подменён ли маршрут.

---

## Как это работает

1. Скрипт читает JSON: один объект-конфиг или массив конфигов.
2. Для каждого конфига:
   - находит первый «настоящий» outbound (пропускает `freedom`, `blackhole`, `dns`);
   - подставляет временный inbound — HTTP-прокси на `127.0.0.1:10808`;
   - запускает `xray.exe run -c <временный конфиг>`;
   - ждёт до 6 секунд, пока порт `10808` начнёт принимать соединения;
   - через этот прокси запрашивает API выбранного сервиса (до 2 попыток);
   - останавливает `xray.exe` и удаляет временные файлы.
3. Все результаты складываются в CSV и выводятся в консоль.

Проверяется только первый подходящий outbound в конфиге — если их несколько, остальные игнорируются.

---

## Требования

- Python 3.10+.
- Любая ОС. Из коробки в комплекте лежит сборка Xray под Windows (`xray.exe`); на Linux/macOS скачайте [Xray-core](https://github.com/XTLS/Xray-core/releases/) под свою систему и укажите путь к бинарю через `XRAY_PATH`.
- Зависимостей, кроме стандартной библиотеки, нет — `requests`/`httpx` не нужны.
- Исполняемый файл Xray. В комплекте — `xray/xray.exe`. Если файла нет или вы на другой ОС, скрипт спросит путь и сохранит его в `.env` как `XRAY_PATH`.
- **ВЫКЛЮЧЕННЫЕ VPN и системный прокси.** Скрипт занимает порт `10808`; если он уже занят другим VPN-клиентом, проверка не запустится или будет недостоверной!

## Запуск

```powershell
cd "2. check_exit_ip"
python get_real_ip.py
```

Скрипт последовательно спросит:

1. **Путь к JSON-файлу конфига.** Можно вставить путь в кавычках, с `&` в начале (PowerShell-стиль) — скрипт это почистит.
2. **Метод проверки:**

| Выбор | Сервис | Что показывает | Особенности |
|---|---|---|---|
| `1` | [2ip.io](https://2ip.io) | IP, страна, город, ASN/провайдер, признак хостинга, ссылка на whois | Нужен бесплатный API-токен (10 000 запросов/мес). Самый подробный отчёт |
| `2` | [ipinfo.io](https://ipinfo.io) | IP, страна, город, организация | Без токена, данных меньше |
| `3` | [ip-api.com](http://ip-api.com) | IP, страна, город, провайдер/ASN, признак хостинга | Резервный вариант, примерно как `2` |

3. **Только для метода 1 — API-токен 2ip.io.** Если `TWOIP_TOKEN` ещё не сохранён, скрипт покажет инструкцию и попросит вставить ключ. Ключ сохраняется в `.env` рядом со скриптом, повторно вводить не нужно.

Получить бесплатный ключ 2ip.io:

1. Открыть <https://2ip.io/ru/free/>.
2. Нажать «Попробовать бесплатно», войти или зарегистрироваться.
3. Скопировать API-токен из личного кабинета.
4. Запустить скрипт и выбрав для анализа 2ip.io вставить API-ключ.

## Результат

CSV-файл: `check_result/<имя_JSON-файла>-exit-<метод>.csv`.

Например, для `configs/my_links.json` и метода `2ip`:

```
check_result/my_links-exit-2ip.csv
```

Кодировка — UTF-8 с BOM, чтобы Excel корректно открывал кириллицу.

### Колонки

| Колонка | Значение |
|---|---|
| `idx` | Номер конфига в исходном файле (с нуля) |
| `name` | `remarks` конфига или `#<номер>` |
| `entry` | Адрес сервера; для домена — `домен (IP, ...)` или `домен (DNS ERR)` |
| `port` | Порт сервера |
| `proto` | Протокол outbound (`vless`, `hysteria`, …) |
| `transport` | Транспорт/безопасность в виде `network/security`, например `tcp/reality` |
| `exit_ip` | Реальный выходной IP |
| `whois_url` | Ссылка на 2ip.io whois (только метод `2ip`) |
| `country` | Код и название страны, например `NL (Netherlands)` |
| `city` | Город или регион |
| `org` | ASN/провайдер, для 2ip и ip-api может быть `[hosting]` |
| `sec` | Время ответа API в секундах |
| `status` | `OK`, `XRAY FAIL`, `HTTP <код>` или `NO RESPONSE` |

### Статусы

| Статус | Что значит |
|---|---|
| `OK` | Xray поднялся, запрос через прокси прошёл, IP получен |
| `XRAY FAIL` | `xray.exe` не стартовал или порт не открылся за 6 секунд; в консоль выводится хвост лога Xray |
| `HTTP <код>` | Сервис ответил ошибкой (например, `HTTP 429` — лимит запросов) |
| `NO RESPONSE` | Запрос через прокси не удался без HTTP-кода (таймаут, обрыв, ошибка прокси) |

В конце выводится сводка: сколько конфигов ответило, сколько уникальных IP получено и распределение по провайдерам (`org`) или по странам.

## Прерывание

Можно нажать `Ctrl+C` в любой момент. Скрипт корректно остановит текущий `xray.exe`, сохранит уже проверенные строки в CSV и выведет пометку «Прервано, но сохранено».

## Настройки через `.env`

Файл `.env` лежит рядом со скриптом (`2. check_exit_ip/.env`) и при запуске создаётся/дополняется автоматически.

| Переменная | Назначение |
|---|---|
| `XRAY_PATH` | Путь к исполняемому файлу Xray. На Linux/macOS укажите здесь скачанный бинарь, например `/usr/local/bin/xray` |
| `TWOIP_TOKEN` | API-токен 2ip.io |


Порядок поиска исполняемого файла Xray:

1. `XRAY_PATH` из `.env`;
2. `.\xray\xray.exe` относительно текущего каталога;
3. `xray\xray.exe` рядом со скриптом;
4. `xray.exe` рядом со скриптом.

Если ничего не найдено — интерактивный запрос пути с сохранением в `.env`. На Linux/macOS проще сразу задать `XRAY_PATH`, например:

```env
XRAY_PATH=/usr/local/bin/xray
```

При необходимости сделайте файл исполняемым: `chmod +x /usr/local/bin/xray`.

Если ключ 2ip.io недействителен или исчерпан, после двух подряд ошибок авторизации (`401`/`403`) проверка останавливается с подсказкой проверить `TWOIP_TOKEN`.

## Нюансы

- Порт локального прокси — `10808`.
- Запрос к API идёт по HTTP через этот прокси, таймаут — 10 секунд, попыток — 2.
- Если в конфиге нет подходящего outbound, адрес будет `?`, а проверка завершится ошибкой запуска Xray.
- Для доменных адресов скрипт предварительно резолвит DNS и показывает полученные IP в колонке `entry`.
- Для `ip-api.com` бесплатный лимит — 45 запросов в минуту; при массовой проверке возможны `HTTP 429`.
- Для каждого конфига создаются временные файлы в системном `%TEMP%` и удаляются после проверки.

---

## Папка `xray/`

Содержит сборку Xray-core под Windows:

- `xray.exe` — ядро;
- `wintun.dll` — компонент для TUN-режима;

Эти файлы трогать не нужно — `get_real_ip.py` находит `xray.exe` автоматически.

Для других ОС скачайте подходящую сборку со [страницы релизов Xray-core](https://github.com/XTLS/Xray-core/releases/) и укажите путь к исполняемому файлу в `XRAY_PATH`. Папку `xray/` при этом можно не трогать.
